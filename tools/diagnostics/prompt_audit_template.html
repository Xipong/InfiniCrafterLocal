Что именно открыто

Трасса stage_requests содержит сообщения до преобразования провайдером и может быть sanitized. .builder.json дополнительно содержит evidence, которое не обязательно входит в запрос. Только сохранённый HTTP body показывает фактическую структуру отправляемого тела. Поля scope / sanitized / evidence ниже не скрываются. Загружайте только файлы, которыми готовы делиться: отчёт содержит полный исходник.
