# contracts/schemas

Generated strict Author/Repair, runtimeProgram, Visual и VFX schemas, а также machine-readable capability/lowering manifests. Полный список выдаёт [export_contract_schemas.py](../../tools/export_contract_schemas.py); собственного legacy attack/runtime-plan контракта здесь нет.

Из корня: `PYTHONPATH=LocalGenerator python tools/export_contract_schemas.py --check` проверяет freshness; без `--check` обновляет export из canonical Python owners. Не редактируй generated JSON вручную.
