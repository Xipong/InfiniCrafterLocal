## Что стало internal/delete

Старые whole-weapon macros, family route tables, `AttackSpec`, `runtimeFamily`, hidden repair API и cache migration удалены. Внутренними остались только: numeric opcode dispatch, DTO field projection, entity-kind → visual-role и технические tModLoader adapters. Они не выбирают movement, attachment, delivery, input, lifecycle или topology.

## Полнота

Каждая public capability имеет Python compiler callable, конкретные C# method symbols, exact final-wire paths и автоматически исполняемый vertical witness. Структурная полнота registry не означает поддержку всего Terraria API: каталог намеренно конечный и включает только реализованные bounded executors.
