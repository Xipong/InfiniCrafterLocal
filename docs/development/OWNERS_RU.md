## Границы приёмки

Fresh Author grammar и persisted recipe/wire lifecycle разные: retirement authoring не разрешает удалять recipes или включать compatibility importer. Profile routing не выбирает механику; missing usage counter ≠ zero, exact-repeat cache ≠ shared-prefix reuse. Read-only prose/UI не становится executor.

Native headless tests используют linked production source и реальные tML/FNA assemblies с private SavePath/TEMP fixture. Compile registration **и** runner invocation нужны вместе, но даже они не результат исполнения; source/CPU/GPU/world/MP/live acceptance разделяются в [TESTING](TESTING_RU.md). Не восстанавливай deleted family/root-lowering/child-spec policies через aliases и не создавай shadow constants/таблицы поведения ради локального PASS.
