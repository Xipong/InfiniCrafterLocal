# move_traveling_wave

A traveling sine displacement around the synchronized initial launch axis: constant authored forward speed plus the exact change of lateral sinusoidal offset across each active update. Amplitude is a world distance, frequency is cycles per second, and phase is explicit. Unlike sine_homing this never selects targets, rotates velocity cumulatively or depends on prior heading; its integrated lateral displacement is bounded by twice amplitude even across extraUpdates. Native integration/collision remains enabled; each next AI recomputes the trajectory velocity from active age. Modifiers may add independent deviations after this driver. Late hydration resumes the same differential step without snapping to a saved origin.

All parameters required. Exact code 23, free/child projectiles only. Author/Repair schemas, prompt cards, compiler receipts and strict wire derive from the registry. Shared synchronized active age and initial direction are used; no additional network payload, no reset at late hydration. Activation waiting is excluded. Normal projectile lifetime and independently authored collision/events apply unless explicitly stated above. Native CPU checks cover the actual executor. GPU/world/multiplayer-session validation: notRun.
