# move_elliptic_orbit

Owner-relative ellipse with independently authored major/minor radii, explicit phase and signed angular speed. The ellipse X axis follows the synchronized initial launch direction, not world X or current cursor; orbit phase uses synchronized active age. Unlike circular move_orbit, non-equal radii and orientation shape a true ellipse and the author chooses initial phase rather than projectile identity. Sets velocity to the next owner-relative point for native integration, and disables tile collision. Normal lifetime applies; invalid/dead owner ends the projectile. Rotation remains tangent to actual velocity. World angular rate is invariant under extraUpdates.

All parameters required. Exact code 22, free/child projectiles only. Author/Repair schemas, prompt cards, compiler receipts and strict wire derive from the registry. Shared synchronized active age and initial direction are used; no additional network payload, no reset at late hydration. Activation waiting is excluded. Normal projectile lifetime and independently authored collision/events apply unless explicitly stated above. Native CPU checks cover the actual executor. GPU/world/multiplayer-session validation: notRun.
