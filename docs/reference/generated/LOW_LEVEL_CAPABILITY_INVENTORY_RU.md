## Техническая граница

Whole-weapon macros, family route tables, `AttackSpec`, `runtimeFamily`, hidden repair API и cache migration не входят в current API. Technical owners исполняют numeric opcode dispatch, DTO field projection, entity-kind → visual-role и точные tModLoader adapters.
Они не выбирают movement, attachment, delivery, input, lifecycle или topology.

<a id="coverage"></a>

## Полнота

Каждая Author-visible capability имеет Python compiler callable, конкретные C# method symbols, exact final-wire paths и автоматически исполняемый vertical witness. Сохранённые compound opcodes проверяются как retained wire, а не повторно компилируются из retired Author. Структурная полнота registry не означает поддержку всего Terraria API: каталог намеренно конечный и включает только реализованные bounded executors.
