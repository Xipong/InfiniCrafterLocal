# Установка и первый крафт

Основной путь для Windows — **готовый мод**, а не сборка исходников. Если ты только подключаешься к другу, установи мод по шагу 2 и перейди к [мультиплееру](MULTIPLAYER_RU.md): остальные шаги выполняет хозяин мира.

## 1. Скачай две части одного релиза

На [странице 0.5.03](https://github.com/Xipong/InfiniCrafterLocal/releases/tag/v0.5.03) открой **Assets** и скачай:

- **`InfiniCrafterLocal.tmod`** — готовый мод для tModLoader;
- **`InfiniCrafterLocal_0.5.03_Source_and_LocalGenerator.zip`** — генератор, Studio и документация. Для генератора нужен весь распакованный архив, даже если ты не будешь менять исходники.

Распакуй ZIP в отдельную папку, в которую можешь записывать файлы. Не запускай BAT внутри окна ZIP. [OPEN_INFINICRAFT.bat](../../OPEN_INFINICRAFT.bat) — приложение для работы.

**Документация в архиве:** [START_HERE.html](../../START_HERE.html) — полная офлайн-книга с поиском; открой её двойным щелчком после распаковки. Для 0.5.03 скачай обе новые части: `.tmod` и архив генератора; исправление текстовых границ затрагивает и Python, и native runtime.

**Результат:** у тебя есть `.tmod` и распакованная папка с `OPEN_INFINICRAFT.bat` и `LocalGenerator`. Если этих файлов нет, проверь, что скачан именно `Source_and_LocalGenerator.zip`, а не автоматический GitHub Source code архив.

## 2. Установи мод

1. Установи Terraria и **stable tModLoader**. Не используй preview-ветку для этой инструкции.
2. В tModLoader установи и включи **ParticleLibrary** и **Luminance** через браузер модов.
3. Открой **Workshop → Manage Mods → Open Mods Folders** (названия зависят от языка игры). Если открылись две папки, выбери пользовательскую **Mods** в сохранениях tModLoader, **не Steam Workshop**. Закрой tModLoader, скопируй туда `InfiniCrafterLocal.tmod`, затем открой tModLoader и включи **InfiniCrafter Local**. Подтверди перезагрузку модов, если игра её предлагает.

Используй именно пользовательскую папку Mods, не каталог Steam и не ModSources. Её расположение зависит от профиля Windows и OneDrive; открытие из игры избавляет от поиска вручную.

**Результат:** мод включён вместе с обеими зависимостями. Версия релиза `0.5.03` в tModLoader может отображаться как **`0.5.3`** — это тот же номер. Если игра сообщает о недостающем моде, установи названную зависимость и перезагрузи моды.

**Только разработчикам:** ModSources и **Build + Reload** нужны при изменении C#-кода. Следуй [инструкции сборки](../development/BUILD_RU.md), а не заменяй ею обычную установку.

## 3. Открой Studio

1. Установи **Python 3.11 или новее** с [python.org](https://www.python.org/downloads/). Оставь компоненты **Tcl/Tk** и **Python Launcher**: Studio использует их, хотя интерфейс открыт в браузере.
2. Дважды щёлкни `OPEN_INFINICRAFT.bat` в распакованной папке.
3. Дождись создания `LocalGenerator/.venv` и установки Python-зависимостей. Для первой установки может понадобиться интернет. Модели этим действием не скачиваются.
4. Откроется **Infinicraft Studio**. Если перенёс старый `config.env`, Studio покажет изменённые рекомендации и предложит принять их или оставить прежние значения; [подробности](SETTINGS_RU.md#обновление-рекомендуемых-значений-0502). Оставь окно запуска открытым. Если браузер не открылся, скопируй напечатанный адрес после `Infinicraft Studio:` целиком, включая часть `?token=…`.

**Результат:** видны **«Рабочий стол»** и разделы настроек. Если окно остановилось на ошибке Python, Tcl/Tk, сети или доступа к папке, исправь названную причину и повтори запуск; [подробная помощь](DIAGNOSTICS_RU.md#studio-не-открывается). Адрес Studio с ключом сессии не передавай другим людям.

## 4. Выбери текст и изображения

В [инструкции по сервисам](PROVIDERS_RU.md) выбери **один** источник текста и **один** источник изображений. Заполни только их обязательные поля:

- **«Идея и механика»** — кто придумывает свойства предмета;
- **«Изображения»** — кто рисует;
- **«Модели и LoRA»** — файлы только для управляемого локального sd.cpp.

Не включай дополнительные линии моделей, запасные источники и LoRA на первом запуске. Шаблон настроек не содержит готовых моделей или аккаунта. Облачные запросы расходуют твою квоту или деньги: сначала проверь условия выбранного сервиса.

Нажми **«Сохранить настройки»**.

**Результат:** Studio сообщает о записи `config.env`, а сводка показывает выбранные тобой источники. Если нужного поля нет, используй **Ctrl+K** и поиск по его названию.

## 5. Запусти генератор

На **«Рабочем столе»** нажми **«Запустить генератор»**, затем **«Проверить»**. Для обычной установки оставь адрес **`127.0.0.1:5055`**: именно к нему обращается мод.

**Результат:** статус **«Сервер отвечает»**. При необходимости открой [health](http://127.0.0.1:5055/health): `version` — `0.5.03`, `serverRoot` и `configPath` указывают на эту распакованную копию, `llmProvider` и `imageBackend` соответствуют твоему выбору, `imageBackendConfigError` пустой. Эта проверка не вызывает нейросеть; ключи и доступность генерации проверятся при крафте.

Если запуск отказал из-за занятого порта или текущей ковки, не открывай второй сервер. Дождись операции или останови старую копию её собственной кнопкой **«Стоп»**. [Другие ошибки](DIAGNOSTICS_RU.md#генератор-не-отвечает).

## 6. Скуй первый предмет в Terraria

1. Создай **«Сердце кузни» (InfiniCore)**: **20 дерева** из группы Wood и **1 упавшая звезда (Fallen Star)**. Верстак для рецепта не нужен. Для теста можно выдать Core командой `/infinicore` в чате.
2. Держи Core в обычном инвентаре и открой инвентарь: появится **«Кузня чудес»**. Core — ключ к панели, его не нужно класть в A или B.
3. Возьми предмет мышью и щёлкни по A; повтори для B. В каждый вход переносится **одна единица**, не весь стек. Эти две единицы расходуются при успешной ковке. Начни с ненужных обычных предметов, не с ценного оружия.
4. Убери остаток стека с курсора и нажми **«Сковать»**. Избранные предметы, пустые слоты и сам Core не подходят. До начала ковки **ПКМ по входу** возвращает материал в инвентарь.
5. Дождись сообщения **«Готово»** и выдачи нового предмета. Шкала в кузне — таймер, а не процент выполнения нейросетью.

**Результат:** получен предмет с названием, описанием и рисунком. Если он не выдан, прочитай статус кузни: при ожидании места освободи место; при ошибке открой **«Диагностика → Обновить журнал → Ошибка»** и [найди причину](DIAGNOSTICS_RU.md#ковка-завершилась-ошибкой). Для отмены используй **«Отмена»** в кузне и дождись подтверждения, вместо закрытия сервера.
