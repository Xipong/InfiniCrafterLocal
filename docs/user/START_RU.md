# Установка и первый крафт — 0.4.254

Этот сценарий предназначен для Windows и **текущего дерева подготовки к альфе**. Он не обещает наличие этих изменений в старом опубликованном архиве. За официальными загрузками обращайся к [Releases](https://github.com/Xipong/InfiniCrafterLocal/releases).

## 1. Подготовь нужные программы

- Terraria и **stable tModLoader**. В tModLoader установи и включи **ParticleLibrary** и **Luminance**.
- **Python 3.11 или новее с Tcl/Tk**: при установке с [python.org](https://www.python.org/downloads/) оставь компоненты Tcl/Tk и Python Launcher. Python нужен локальному генератору, а не самой Terraria.
- Выбранный текстовый сервис/модель **и** сервис изображений. Это два независимых маршрута. Для полностью локального режима понадобятся уже скачанные модель текста, image weights и совместимый image server. Проект их автоматически не скачивает.

Облачный сервис может быть платным; проверь свои условия и квоты до крафта. Готовый GUI-профиль не создаёт аккаунт и не устанавливает модели.

## 2. Распакуй и открой приложение

1. Полностью распакуй проект в свою папку. Не запускай BAT из окна ZIP.
2. Открой **[OPEN_INFINICRAFT.bat](../../OPEN_INFINICRAFT.bat)** в корне.
3. Дождись подготовки `LocalGenerator/.venv` внутри проекта и установки зависимостей из локального `LocalGenerator/requirements.txt`. Зависимости Python могут потребовать интернет; модели не загружаются.
4. Откроется **Infinicraft Studio** в твоём браузере. Это локальное приложение: настройки и управление находятся на твоём компьютере. Оставь окно запуска открытым. Если браузер не открылся автоматически, скопируй напечатанный `Infinicraft Studio: http://127.0.0.1:...` адрес целиком. При ошибке окно BAT сохраняет сообщение: исправь причину, затем открой его снова.

Не устанавливай runtime через системный `pip` и не запускай несколько экземпляров сервера на одном порту. [Старые нумерованные входы](OPERATIONS_RU.md#установка) сохранены для отдельных действий.

## 3. Настрой текст и изображения

1. В разделе **«Текстовые модели»** выбери текстовый маршрут. Для LM Studio загрузи свою модель и запусти его локальный API server; проверь адрес и model ID. Для удалённого сервиса укажи его адрес/модель и свои credentials.
2. В разделе **«Изображения»** выбери отдельный источник. Для внешнего sd.cpp укажи адрес работающего сервера и оставь автозапуск выключенным. Для управляемого запуска выбери реальные exe/weights и включи автозапуск.
3. На первом запуске не меняй advanced pool/retry/resize параметры. Стиль **Default / Terraria Like** выбирает художественное направление, не провайдера и не механику.
4. Нажми **«Сохранить настройки»**. Рабочий файл — `LocalGenerator/config.env`; шаблон `config.example.env` не применяется сам по себе.

Подробности выбора и обработки PNG — [настройки](SETTINGS_RU.md). OAuth-маршрут требует собственной сессии и доступности функций аккаунта: [отдельная инструкция](CODEX_IMAGE_OAUTH_RU.md).

## 4. Запусти генератор и проверь ответ

1. Нажми **«Запустить сервер»**. При принятом запуске приложение сохраняет поля и запускает сервер. Это отдельное действие от открытия GUI.
2. В **«Диагностике»** проверь статус сервера и применённые настройки. Если порт занят другой копией, не убивай неизвестный процесс: сначала выясни его владельца.
3. Открой [http://127.0.0.1:5055/health](http://127.0.0.1:5055/health). Проверь `version=0.4.254`, правильные `serverRoot`/`configPath`, выбранные `llmProvider`/`imageBackend` и отсутствие `imageBackendConfigError`.

`ok=true` означает только ответ HTTP-сервиса. Это **не** проверка ключа, квоты, фактического image endpoint или успешного создания предмета. По умолчанию оставь `127.0.0.1:5055`: мод обращается к этому адресу. [Если не отвечает](DIAGNOSTICS_RU.md).

## 5. Установи мод отдельно

1. Сохрани свои изменения в ранее установленном `ModSources/InfiniCrafterLocal`, если они есть.
2. Открой **[01_INSTALL_MOD_TO_TMODLOADER.bat](../../01_INSTALL_MOD_TO_TMODLOADER.bat)**. Он копирует исходники мода в пользовательский ModSources и **удаляет старую одноимённую папку**.
3. В tModLoader открой **Workshop → Develop Mods → Build + Reload** для InfiniCrafterLocal. Проверь версию и включённые зависимости.

Для нестандартного ModSources и внешних DLL смотри [сборку](../development/BUILD_RU.md). Открытие генератора не устанавливает мод, Terraria или image server.

## 6. Сделай первый предмет

1. Получи **«Сердце кузни» (InfiniCore)**: рецепт — 20 единиц дерева из группы Wood и 1 Fallen Star. Для dev-проверки доступна команда `/infinicore`.
2. Держи Core в инвентаре и открой инвентарь: появится **«Кузня чудес»**.
3. Положи два предмета во входы **A** и **B**. Пустой слот, избранный предмет и сам Core не подходят.
4. Запусти крафт и дождись результата. Не закрывай сервер во время операции. Индикатор не гарантирует ETA; результат выдаётся после готовности контрактов и обязательного PNG.
5. При ошибке смотри её стадию в [диагностике](DIAGNOSTICS_RU.md), а не запускай параллельный сервер.

В мультиплеере генерирует только хозяин/сервер: [сценарий для друзей](MULTIPLAYER_RU.md). Перед обновлением — [сохрани личные данные](UPDATING_RU.md).
