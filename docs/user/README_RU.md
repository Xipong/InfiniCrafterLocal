# Руководство Infinicraft

Infinicraft добавляет в Terraria **«Кузню чудес»**: ты отдаёшь по одному предмету во входы A и B, а нейросети придумывают и рисуют новый. **Мод** показывает кузню и исполняет механику в игре. **LocalGenerator** создаёт предметы вне игры. **Studio** — локальная страница для настройки и запуска LocalGenerator, а не место крафта.

## Что обязательно, а что можно отложить

**Для одиночной игры и хозяина мира:** готовый `.tmod`, игровые зависимости, Python для LocalGenerator, один источник текста и один источник изображений. Текст и изображения выбираются отдельно: например, OpenRouter может придумывать механику, а локальный sd.cpp — рисовать.

**Для гостя:** та же версия мода и игровые зависимости. Никаких личных API-ключей для игры у друга не требуется.

**Необязательно:** LoRA, дополнительные текстовые модели, ручная настройка обработки рисунка, HTTP-доставка изображений друзьям и сборка исходников. Оставь их на потом, пока первый крафт не заработает.

Рабочая последовательность: **установить мод → открыть Studio → подключить два источника → сохранить → запустить генератор → сковать предмет в Terraria**. Успешный результат — новый предмет с описанием и рисунком в игре; ответ сервера сам по себе ещё не проверяет нейросети.

## Как читать руководство

Названия **жирным** — кнопки и разделы приложения. Значения в `моноширинном шрифте` — имена файлов, параметры или команды. Если поле не видно, нажми **Ctrl+K** в Studio и найди его по русскому названию или ключу `INFINI_…`. Скрытые параметры сохраняются при смене источника.

[Офлайн-версия всего руководства](../../START_HERE.html) открывается отдельно от Studio. Если ты хочешь изменять код, начни со [сборки для разработчиков](../development/BUILD_RU.md).
