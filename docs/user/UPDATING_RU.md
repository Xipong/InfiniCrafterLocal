# Обновление и граница поддержки

Обновляй **мод и генератор вместе из одного релиза** с [GitHub Releases](https://github.com/Xipong/InfiniCrafterLocal/releases). В мультиплеере все участники используют одну сборку мода; генератор настраивает хозяин мира.

## Текущая ветка: ломающая граница

Эта ветка поддерживает только текущие конфигурацию, Author/Repair, runtime wire и VFX. Совпадение номера приложения, `schemaVersion=5` или runtime API v5 само по себе не подтверждает пригодность старого предмета. Эти изменения исходников не означают, что опубликованный релиз уже заменён: состав готовой поставки проверяй по её release notes и Assets.

- `config.env` принимается только в формате `json-string-v1` с текущими ключами. Автоматического переноса старых ключей, fallback-профилей и прежних настроек нет.
- Native reader принимает только текущий контракт определения. Неподдерживаемые исполняемые формы отклоняются. При новом запросе крафта генератор сохраняет невалидную запись world cache побайтно в quarantine и рассматривает рецепт как cache miss; затем может выполнить обычную генерацию этого запроса. Загрузка существующего предмета не запускает его переавторство.
- PNG доступны только через индекс текущего постоянного image store. Старые `cache/sprites`, `asset_cache` и каталоги диагностических изображений не импортируются и не сканируются для восстановления.
- Родословная использует сохранённые точные `parentIdentities` текущего определения. Пропущенные связи не вычисляются по имени, hash рецепта или другим кэшам.

Переход **не обещает исполнение всех ранее созданных предметов**. Не меняй markers/schema вручную и не удаляй единственную копию старых данных. Оставь прежнюю пару мод + генератор с её резервной копией для старых предметов; новую сборку сначала проверяй в отдельном профиле на копиях. Новая установка не должна перезаписывать неподдерживаемые исходные файлы ради допуска.

## 1. Останови работу и сделай копию

1. Дождись результата ковки либо подтверждённой отмены и возврата материалов.
2. Останови генератор в Studio, затем закрой tModLoader.
3. Сохрани миры, персонажей и всю папку `InfiniCrafterLocal/` в пользовательских сохранениях tModLoader.
4. Сохрани фактические настройки, профили, recipes и image store вместе с индексом, не только отдельные PNG.

| Данные | Обычный путь / настройка |
|---|---|
| Встроенная Studio: настройки и cache | `<Main.SavePath>/InfiniCrafterLocal/Studio/data/` |
| Общие PNG игры и встроенной Studio | `<Main.SavePath>/InfiniCrafterLocal/images/`, включая `.index/` |
| Внешний генератор: настройки | `generator/config.env`, `config.env.defaults.json`, `gui_user_presets.json`, если есть |
| Внешний cache и recipes | `INFINI_CACHE_DIR`, `INFINI_WORLD_RECIPES_DIR`; обычно `generator/cache/` и `cache/world_recipes/` |
| Внешний image store | `INFINI_IMAGE_DIR`; обычно `generator/images/` |

До остановки сверь действующие пути в [health](http://127.0.0.1:5055/health). Сохрани также старую установку и `.tmod`. Копии конфигурации могут содержать секреты; не публикуй их.

## 2. Установи согласованную пару

1. Замени готовый `.tmod` при закрытой игре. Для внешнего запуска распакуй соответствующий архив генератора **в новую папку**, не поверх старой.
2. Не переноси `.venv`, Python/C#-файлы или скрипты из прежней установки. Для встроенной Studio один раз открой **IFC в меню нового мода**, чтобы установить его runtime и обновить открывалку.
3. Если настройки уже текущего формата, используй их копию и проверь пути. Для неподдерживаемой конфигурации создай новый файл из актуального `config.example.env` либо через Studio; перенеси нужные значения вручную по [справочнику настроек](SETTINGS_RU.md#формат-configenv). Исходный файл оставь отдельно.
4. Не направляй две установки в один cache/image store. Для проверки выбирай копии данных или отдельный профиль. Локальные модели и внешние image servers остаются отдельными ресурсами.

Вход ChatGPT привязан к пользовательскому профилю. На другом ПК войди заново, не копируй OAuth-сессию как конфигурационный файл. Разработчику — [сборка](../development/BUILD_RU.md); установщик исходников заменяет пользовательский ModSources и не нужен для готового `.tmod`.

## 3. Проверь новую установку

1. В Studio проверь источники, модели и пути, сохрани настройки и запусти генератор.
2. Нажми **«Проверить»**: `serverRoot`, `configPath`, `effectiveConfig.cacheDir` и `worldRecipesDir` должны соответствовать выбранной установке. Health подтверждает ответ сервера, не качество модели, игровые эффекты или MP.
3. На копии сохранений проверь поддерживаемые предметы: определение, PNG, механику, сохранение и повторную загрузку. При отказе сохрани точную причину. `/getinfini` синхронизирует существующее текущее определение, но не преобразует старый формат и не восстанавливает утраченные файлы.
4. Новый [тестовый крафт](START_RU.md#6-скуй-первый-предмет-в-terraria) выполняй только когда готов расходовать квоту и материалы. Он не служит способом ремонта старого предмета.

При проблеме останови новую установку и сохрани [диагностику](DIAGNOSTICS_RU.md). Возврат выполняется согласованно: старая пара мод + генератор **и её резервные данные**, а не один старый `.tmod` поверх новых записей. Техническая граница — [engine runtime](../development/architecture/ENGINE_RUNTIME_BOUNDARIES_RU.md#saved-v5).
