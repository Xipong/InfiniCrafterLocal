# Обновление без потери данных — 0.5.00

1. Дождись завершения craft, затем безопасно останови сервер. Не приравнивай отсутствие ответа к завершённой операции.
2. Сделай резервную копию `LocalGenerator/config.env`, `gui_user_presets.json`, effective cache/world-recipes roots, PNG, player/world saves и собственных изменений мода. Paths могут быть переназначены `INFINI_CACHE_DIR`/`INFINI_WORLD_RECIPES_DIR`.
3. Обновляй **мод и LocalGenerator вместе** из согласованного дерева/официальной поставки. Для 0.5.00 протокол станции v2 требует одновременного обновления мода у host и всех клиентов; v1-пакеты отвергаются. Не подменяй личный `config.env` шаблоном.
4. Открой `OPEN_INFINICRAFT.bat`: окружение `LocalGenerator/.venv` подготовится под runtime requirements этой копии. Затем установи исходники мода и Build + Reload. Installer удаляет прежний одноимённый ModSources; резервируй локальные правки до этого.
5. Проверь версию/root/config по health и версию мода в tModLoader. Offline gates и старые release notes не доказывают успешность новой установки.

Корректные старые recipes/PNG **не мигрируют, не переавторствуются и не перерисовываются автоматически**. Новое style/collision guidance применяется к будущей генерации. Legacy schema/cache importer не является поддерживаемым путём.

Модели, внешние DLL и OAuth-сессии остаются отдельными пользовательскими ресурсами. Условия оригинальных загрузок — [LICENSE](../../LICENSE), [перевод](../../LICENSE_RU.md). Старые релизные детали сохранены в [архиве](../archive/README_RU.md); это не обещание публикации текущей альфа-подготовки.
