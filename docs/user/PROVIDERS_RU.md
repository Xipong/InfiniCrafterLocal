# Подключить нейросети

Нужны **два независимых источника**: текстовый придумывает механику и описание, источник изображений рисует PNG. Их можно сочетать: например, ChatGPT для текста и sd.cpp для рисунка. Название модели бери из своего сервиса точно, а не из чужого примера.

## Выбери вариант

| Что у тебя уже есть | Источник текста | Источник изображений |
|---|---|---|
| Аккаунт ChatGPT с доступом к нужным функциям | ChatGPT / Codex | ChatGPT / Codex, если аккаунту доступен этот маршрут |
| API-ключи облачных сервисов | OpenRouter или Совместимый API | Внешний Image API |
| Подготовленные локальные модели и серверы | LM Studio | sd.cpp; также доступны Automatic1111 и ComfyUI |

Локальный вариант требует самостоятельно установить модели и совместимые программы. Облачный — аккаунт, доступ к выбранной модели и квоту/оплату. В комплекте их нет. Для первого предмета подключи один текстовый источник и один источник рисунка, без дополнительных линий и запасных моделей.

## Текст: обязательные поля

Открой **«Идея и механика → Источник идей и механики»**. Оставь **«Авторство нейросети»** включённым.

### LM Studio · локально (`local`)

1. В LM Studio скачай и загрузи свою текстовую модель, затем запусти **локальный API server**.
2. В Studio укажи **«Адрес LM Studio»** — например, `http://127.0.0.1:1234`, если LM Studio действительно слушает этот порт.
3. В **«Локальная текстовая модель»** вставь ID загруженной модели. `auto` допустим, если сервер сам выбирает модель, но явный ID проще проверить.

**Результат:** модель загружена, API server работает, адрес и ID в двух приложениях совпадают. При `connection refused` запусти API server и проверь порт; при `model not found` исправь ID. Открытого окна чата LM Studio недостаточно.

Для другого локального OpenAI-совместимого сервера можно использовать **«Совместимый API»** ниже с его адресом и ID.

### OpenRouter (`openrouter`)

1. Выбери **OpenRouter** и заполни **«Ключ OpenRouter»** своим API-ключом.
2. В **«Модель OpenRouter»** вставь точный ID в формате `owner/model` из каталога OpenRouter.
3. **«Площадка OpenRouter»** оставь пустой, чтобы сервис выбирал её сам. Заполняй её только при необходимости [строго зафиксировать площадку](OPENROUTER_ROUTING_RU.md).

**Результат:** выбран конкретный model ID и сохранён ключ. При отказе авторизации проверь ключ; при исчерпанной квоте — баланс и ограничения аккаунта; при недоступной модели — её текущий статус в OpenRouter.

### Совместимый API (`openai_compat`)

1. Выбери **«Совместимый API»**.
2. Заполни **«Адрес совместимого API»** базовым адресом из документации сервиса, например `https://api.example.com/v1`. Это пример адреса, не действующий сервис. Не добавляй `/chat/completions` к базовому адресу.
3. Вставь **ключ** и точное имя **модели**. Для локального сервера, не требующего авторизации, поле ключа может оставаться пустым.

При `404` проверь базовый адрес. Если сервис отклоняет формат запроса, открой **«Тонкая настройка»**: для API с Chat Completions выбери **«Формат запроса к модели» → `chat_completions`**; формат ответа выбирай из поддерживаемых сервисом (`auto`, `json_object` или `json_schema`). После изменения сохрани и безопасно перезапусти генератор. Надпись «OpenAI-compatible» не гарантирует поддержку каждого формата каждой моделью.

### ChatGPT / Codex (`openai_codex`)

Здесь нужен **вход через браузер**, не Platform API key. Пройди [инструкцию входа](CODEX_IMAGE_OAUTH_RU.md), обнови список текстовых моделей и выбери доступную своему аккаунту. Успешный вход сам по себе не подтверждает доступ к изображениям.

## Изображения: выбери один источник

Открой **«Изображения → Источник изображений»**. В обычной игре рисунок предмета обязателен: **«Без изображений»** не является способом получить готовый предмет без настройки.

### sd.cpp: внешний сервер уже запущен

1. Выбери **«sd.cpp · локально»**.
2. **«Способ запуска sd.cpp» → «Внешний · уже запущен»**.
3. Укажи **«Адрес sd.cpp»**, например `http://127.0.0.1:7861`, если твой сервер работает там.
4. Модель и параметры запуска подготовь в самом sd.cpp. В этом режиме локальные поля программы и файлов модели в Studio не обязательны.

**Результат:** отдельный sd.cpp работает и обслуживает выбранный адрес. Если генератор сообщает, что sd.cpp недоступен, проверь его окно/журнал и URL, не переключай автозапуск только ради исчезновения ошибки.

### sd.cpp: запускать из Infinicraft

1. Выбери **«sd.cpp · локально» → «Управляемый · запускать здесь»**.
2. В **«Модели и LoRA»** укажи **«Программа sd.cpp»** (обычно `sd-server.exe`) и **«Диффузионная модель»**.
3. Укажи совместимые **VAE / AE** и **текстовый энкодер**, если они требуются твоей модели/сборке. Выбирай существующие файлы через кнопки папки.
4. В **«Изображениях»** оставь автоматический способ формирования команды (`safe_args`). Размер, шаги, CFG и сэмплер должны подходить твоей модели; готовый профиль используй только для совпадающего набора модели и оборудования.
5. Нажми **«Проверить пути»**, сохрани настройки и запусти генератор. sd.cpp запускается при необходимости изображения, не от проверки файлов.

**Результат:** проверка не сообщает об ошибках указанных файлов; при крафте sd.cpp запускается. Проверка путей не проверяет полную совместимость моделей и может не заметить пустое поле — программа и основная модель всё равно обязательны. При неизвестном аргументе проверь совместимость сборки и **«Дополнительные аргументы»**; при нехватке памяти уменьши исходный размер, оставь **«Параллельных изображений» = 1** или выбери подходящий своей сборке режим разгрузки. Не копируй GPU-флаги от чужой видеокарты.

### Внешний Image API (`image_api`)

Заполни **«Адрес API изображений»**, **«Ключ API изображений»**, **«Модель изображений API»** и поддерживаемый ею размер. Базовый адрес и **«Путь API генерации»** задаются отдельно: например, `https://api.example.com/v1` плюс `/images/generations`. Полный путь ищется через **Ctrl+K**.

**Результат:** выбрана модель именно для изображений, не текстовая модель. При `401/403` проверь её доступность и ключ; при `400` — поддерживаемые размер и формат; при `404` — базовый адрес и путь. Текстовый ключ OpenRouter не переносится сюда автоматически.

### ChatGPT / Codex: изображения (`openai_codex`)

Используется та же собственная сессия ChatGPT, но отдельная модель и отдельный доступ к функции. Выбери источник и следуй [инструкции OAuth](CODEX_IMAGE_OAUTH_RU.md#выбрать-изображения).

### Если уже используешь Automatic1111 или ComfyUI

- **Automatic1111:** запусти его с доступным API (обычно требуется `--api`), загрузи модель, выбери **Automatic1111** и укажи **«Адрес Automatic1111»**. Пример локального адреса — `http://127.0.0.1:7860`.
- **ComfyUI:** нужен не только сервер, но и рабочая схема в **API JSON** с установленными узлами и моделями. Выбери **ComfyUI**, укажи **«Адрес ComfyUI»** (обычно `http://127.0.0.1:8188`) и в `config.env` задай `INFINI_COMFYUI_WORKFLOW` — путь к своей схеме; относительный путь считается от `LocalGenerator`. В схеме используются подстановки `{{PROMPT}}`, `{{NEGATIVE_PROMPT}}`, `{{SEED}}` и другие параметры. Например, `{{CHECKPOINT}}` берётся из `INFINI_COMFYUI_CHECKPOINT`. Схема должна сохранять изображение, которое можно скачать через ComfyUI. Готового workflow в этой поставке нет: один URL без схемы не завершает настройку.

Если ошибка называет неизвестный узел, checkpoint или workflow, исправь это в соответствующем приложении/схеме. Для первой установки без опыта этих программ проще один из вариантов выше. Подробности подстановок — в [обработчике изображений](../../LocalGenerator/infini_local/pipelines/image_backend_pipeline.py).

## Сохранить и проверить выбранное сочетание

1. Нажми **«Сохранить настройки»**.
2. На **«Рабочем столе»** нажми **«Запустить генератор»** или **«Перезапустить безопасно»**, если он уже работает.
3. Нажми **«Проверить»** и сверь оба источника в сводке.
4. Сделай [первый крафт](START_RU.md#6-скуй-первый-предмет-в-terraria) из ненужных предметов. Это реальный запрос к выбранным сервисам.

Если сломался текст или рисунок, меняй настройки **того источника, который назван в ошибке**. [Таблица ошибок](DIAGNOSTICS_RU.md#ковка-завершилась-ошибкой) поможет не лечить квоту сменой формата JSON. [Профили и внешний вид](SETTINGS_RU.md) настраиваются после работающего первого крафта.
