# toolbox/tests

`test_live20_support_v5.py` проверяет офлайн-выбор кейсов, соответствие стадий и температур, учёт HTTP-повторов и детерминированный результат параллельной обработки. Тесты не обращаются к провайдеру и не запускают генерацию изображений или Terraria. Запуск: `PYTHONPATH=LocalGenerator python -m pytest toolbox/tests -q` из корня проекта.
