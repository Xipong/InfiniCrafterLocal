# toolbox

Версионируемый автономный no-image Live20 harness. `infini_toolbox.py` ищет текущий worktree и читает локальную конфигурацию провайдера, не записывая её в Git. `README.md` содержит инструкцию по запуску и границы проверки. Никакой код этой папки не импортируется игровым модом.

- `live-generation/` — сетевой acceptance runner, который жёстко блокирует генерацию изображений.
- `fixtures/` — побайтовый фиксированный Terraria runtime dump для автономного preflight.
- `tests/` — только локальные детерминированные тесты harness без сетевых вызовов.
