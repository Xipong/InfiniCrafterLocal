# Terraria / tModLoader: гайд по тикам для runtime-authoring LLM

Короткая шпаргалка для чисел в `runtimePlan.engineCalls`. В Terraria логика обычно идёт с частотой **60 тиков в секунду**.

## Базовые переводы времени

| Тики | Секунды | Комментарий |
|---:|---:|---|
| 6 | 0.10 с | Очень мало. Обычно не использовать для `useTime`: C# рантайм зажимает минимумом 10. |
| 10 | 0.17 с | Очень быстрое оружие / быстрый расходник. Нижняя граница для generated runtime. |
| 12 | 0.20 с | Быстрый шот/метание, уже агрессивно. |
| 15 | 0.25 с | Быстро, но ещё нормально для ранних метательных/луков. |
| 20 | 0.33 с | Быстрое обычное оружие. |
| 24 | 0.40 с | Нормальная универсальная скорость. Хороший дефолт. |
| 30 | 0.50 с | Среднее/тяжелее среднего. |
| 45 | 0.75 с | Медленное оружие. |
| 60 | 1.00 с | Очень медленное / заряжаемое. |
| 90 | 1.50 с | Долгий заряд/особое оружие. |
| 120 | 2.00 с | Почти только для heavy/charge. |
| 180 | 3.00 с | Долгое существование снаряда или поле, не useTime для обычного оружия. |

## `useTimeTicks` и `useAnimation`

`useTimeTicks` — как часто предмет может применять действие. Меньше число = быстрее DPS/больше спама.

Практические диапазоны:

- **10–14**: очень быстро. Только слабый урон, расходник, короткая дальность или сильный минус.
- **15–22**: быстрое оружие. Нормально для дротиков, кинжалов, лёгких стрел.
- **23–34**: обычная скорость. Безопасный диапазон для большинства generated-оружия.
- **35–55**: медленное оружие. Подходит для тяжёлых болтов, молотов, сильных выстрелов.
- **56–90**: очень медленно. Только heavy/charge/особый эффект.

Для generated runtime не ставить `useTimeTicks < 10`: движок всё равно зажмёт до 10.

## `lifetimeTicks` снаряда

`lifetimeTicks` — сколько тиков живёт снаряд.

- **8–16**: микрофрагменты/щепки после попадания.
- **20–35**: короткий secondary projectile.
- **45–75**: короткая/средняя дальность.
- **90**: 1.5 секунды, хороший дефолт для стрелы/дротика.
- **120–180**: дальний выстрел/долгая дуга.
- **240+**: осторожно, может копить много активных снарядов.

## Оценка дальности

Грубая формула:

```text
rangeTiles ≈ speed * lifetimeTicks / 16
```

Пример: `speed=8`, `lifetimeTicks=90` → около `45 tiles`.

## `extraUpdates`

`extraUpdates` делает снаряд более гладким/быстрым по симуляции, но дороже для CPU/сети.

- **0**: дефолт, почти всегда достаточно.
- **1**: быстрый точный снаряд, осторожно.
- **2+**: только для особых случаев, не для массовых child-снарядов.

## Child / secondary projectiles

Для `spawn_secondary_projectiles(trigger=on_hit)`:

- `count=1–3`: нормальный малый split.
- `count=4–6`: заметный split, уже дорого/эффектно.
- `count=7–8`: только если это основная фишка предмета.

Типовые параметры:

```json
{
  "fn": "spawn_secondary_projectiles",
  "params": {
    "trigger": "on_hit",
    "count": 3,
    "spreadRadians": 0.35,
    "damageMultiplier": 0.25,
    "lifetimeTicks": 12,
    "sameTargetBias": 0.75
  }
}
```

Это означает: при попадании 3 коротких осколка, обычно рядом с той же целью, малый урон, без отдельного фейерверка.

## Dust / VFX

- `effect="none"`, `amount=0` → вообще без пыли.
- `effect="dust"` → физическая пыль/опилки/осколки, не магия.
- `effect="flame/electric/star/lunar/holy/shadow"` → можно свет/свечение, если источник это оправдывает.

Для mundane-родителей (`wood`, `stone`, `copper`, `iron`, `sand`) не добавлять glow/light/motes без причины.

## Типовые пресеты

### Лёгкий дротик / щепа

```json
{
  "fn": "shoot_projectile",
  "params": { "delivery":"shoot", "movement":"straight", "speed":8.0, "lifetimeTicks":75, "useTimeTicks":18, "pierce":0 }
}
```

### Лукоподобный выстрел

```json
{
  "fn": "shoot_projectile",
  "params": { "delivery":"shoot", "movement":"gravity_arc", "speed":9.0, "lifetimeTicks":90, "useTimeTicks":24, "pierce":0 }
}
```

### Тяжёлый болт / арбалет

```json
{
  "fn": "shoot_projectile",
  "params": { "delivery":"shoot", "movement":"straight", "speed":10.0, "lifetimeTicks":90, "useTimeTicks":35, "pierce":1 }
}
```

### Обычный контактный эффект без магии

```json
{
  "fn": "spawn_contact_particles",
  "params": { "effect":"dust", "material":"wood", "amount":8, "scale":0.45 }
}
```

### Полностью без VFX

```json
{
  "fn": "spawn_contact_particles",
  "params": { "effect":"none", "amount":0 }
}
```
