# v0.4.239 — quick start

1. Установить зависимости генератора: `cd LocalGenerator && python -m pip install -r requirements-dev.txt`.
2. Проверить Python: `python -m pytest -q`.
3. Проверить repo contracts из корня: `python tools/check_project_hygiene.py`, `python tools/check_csharp_contracts.py`, `python tools/check_planner_prompt_usability.py`.
