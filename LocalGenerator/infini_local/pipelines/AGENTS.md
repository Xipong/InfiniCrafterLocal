# Правки промптов: инструкции для контрибьютора и его ИИ-ассистента

Наследуй [Python AGENTS](../AGENTS.md). Этот файл направляет работу над исходниками, **не входит в запросы к модели, генерирующей предмет**.

Проектируй промпт от желаемого результата, доступного контекста и проверяемого контракта. Не переноси в приложение привычки своего coding-ассистента или ритуалы старых моделей: «подумай тщательно», обязательный отчёт о рассуждениях, длинные превентивные запреты и уроки очевидных типов. Для каждой добавленной фразы спроси, даёт ли она нужную для решения информацию, которой ещё нет в соседних именах, типах, флагах или примерах.

Неочевидные частные факты движка оставляй один раз у владельца соответствующей механики. Схемы, ограничения и реальные execution semantics — не декоративный текст: их изменение требует отдельного обоснования и проверок. Оценивай весь фактический provider payload, включая response schema, а не только видимый текст сообщений. Пояснения для человека не обязаны становиться инструкциями модели.

Это стандарт редактирования, а не запрет конкретных coding-моделей, новая матрица целевых моделей или требование платного A/B. Уменьшение текста само по себе не доказывает улучшение результата; рекомендации конкретной модели не универсальны.
