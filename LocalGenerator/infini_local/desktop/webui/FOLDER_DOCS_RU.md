# Локальная веб-мастерская Infinicraft

## Владение

`index.html` — семантический shell, SVG-иконки, навигация и диалоги.
`studio.css` — адаптивная авторская композиция, типографика, фокус и состояния.
`studio.js` — клиент локального bridge, черновик, поиск, формы и подтверждения.
`assets/` — локальные шрифты Manrope / Cormorant Garamond (WOFF2), исходные SIL OFL лицензии и знак мастерской. На стороне браузера нет CDN, пакетов, облачных сервисов и платных вызовов.

Первичная поверхность — **Operate**: реальное состояние и запуск генератора, справа последовательная сборка, ниже активность и следующий шаг. Вторичная — **Configure**: индекс этапов, профили и редактируемые параметры. Визуальная система: тёплая бумага, графитовая навигация, кислотный chartreuse только для главного действия / выбора, контраст редакционной антиквы и точного гротеска. Без фальшивых предметов, метрик и SaaS-карточек.

## Контракт

Сервер подставляет `window.INFINI_BOOTSTRAP.token`. Каждый API-запрос, включая GET `/api/state`, отправляет `X-Infini-Token`. POST `/api/action` передаёт `{action, values, extra}`. URL запуска сохраняется для авторизованного обновления вкладки; токен не выводится в интерфейс, журнал или поля.

Поля и LAN-значение фиксируются до отправки POST; submitted-поля защищены от polling уже до получения action id. Правка после отправки остаётся несохранённой. Ответ POST означает только постановку в очередь. Клиент ждёт `lastAction.id`, учитывает `revision`, сохраняет введённые после отправки изменения через локальные номера правок. Успешное сохранение подтверждается `lastAction.ok` и реальным `status` с префиксом `Saved:`. Ответ студии не означает, что генератор готов; рабочий стол показывает `home` от backend. Пулы, секреты и готовность всех моделей не выдаются за проверенные.

Черновик и секреты живут только в памяти вкладки. Polling не затирает dirty-поля; нет localStorage/sessionStorage с настройками. Password-поля содержат исходные значения, а не звёздочки. `beforeunload` защищает несохранённое; Ctrl+S сохраняет, Ctrl+K ищет по всем ключам и описаниям. Поиск не индексирует значения/секреты.

Все поля backend имеют доступ через разделы, глобальный поиск и раскрытие «Все параметры». INFINI-параметры вне метаданных также доступны как дополнительные поля, значения передаются без нормализации. Неактивные поля не удаляются. Активность источников вычисляется по **локальному черновику**, а не устаревшему `fields.disabled`.

sd.cpp: сначала источник / способ запуска / URL. Внешний запуск не требует локальных EXE / весов. Управляемый запуск открывает их в «Модели и LoRA»; адаптеры и технические параметры вынесены в disclosure. Крафт остаётся в Terraria; UI не предлагает фиктивную генерацию.

## Проверка

Для проверки нужен настоящий loopback bridge; открывать файл напрямую недостаточно. Desktop/mobile проверены Chromium на реальном parent-owned bridge с изолированным конфигом, `INFINI_IMAGE_BACKEND=off`, `INFINI_USE_LLM=0` — без запросов моделей / игры. Проверены загрузка локальных шрифтов, поиск Enter, защита черновика на polling, save + GET read-back, доступность всех 129 backend-полей и отсутствие горизонтального overflow на 390 px. JS не требует unsafe-eval; Node syntax check и console/pageerror чистые.

Native browse / OAuth / принудительный restart требуют интерактивного хоста. Они подключены к существующим действиям bridge; файловый выбор не имитируется браузерным fake path. Очистка, остановка, reset и force restart имеют явное подтверждение. Принудительный restart также передаёт `extra.confirm=true`.

## Границы

Runtime, процессы, нативные диалоги, OAuth, disk writes и безопасность shutdown принадлежат `web_studio.py` и существующему desktop controller. WebUI не дублирует backend авторитет. Закрытие студии не равно Stop генератора.
