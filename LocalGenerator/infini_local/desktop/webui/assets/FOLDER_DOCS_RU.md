# Локальные ресурсы Infinicraft Studio

WOFF2 Manrope и Cormorant Garamond обслуживаются локально, без Google Fonts/CDN.
Сопутствующие OFL-файлы сохраняют лицензии и notices upstream; они не заменяются
лицензией проекта. `mark.svg` — знак мастерской. Файлы не содержат пользовательских
данных, ключей или generated item assets.
