# Behavioral test selection

Prefer a public compiler/validator, serialized provider request, HTTP route, or
observable GUI callback over source text, private helper identity, or internal
bookkeeping snapshots. Test distinct risks with named representative cases;
provider × format × stage products are not a default coverage requirement.

This pass retires duplicate prompt/help phrase catalogs, private schema/import
ownership microchecks, exhaustive scalar-projector experiments, exact diagnostic
key/count snapshots, and repeated binding/transport cross-products. It retains
real offline protocol routing/auth/deadline/error tests, capability compilation
and source authentication, malformed-output refusal, exact frozen Repair closure,
GUI nonblocking/latest-result behavior, and settings/cache preservation scenarios.
Archived response fixtures are unchanged. This is a pragmatic portfolio change,
not a claim that every historical microassertion has an equivalent replacement.

The GUI portfolio uses real callbacks with one UI-thread scheduler/held-worker
seam and recording processes. It keeps save/reload and named-profile preservation,
nonblocking/latest-result/cancel behavior, selected-cache safety, guarded shutdown,
and bounded non-secret activity feedback. Duplicate thread/process setup, private
acknowledgement snapshots, provider-alias products, widget/help/source catalogs and
exhaustive resize/keyer combinations are intentionally retired. Codex catalog
checks share the scheduler and retain saved choices, safe errors and logout/stale
result retirement; they do not contact a real account.

The native portfolio keeps gameplay/authority, craft cancellation and deadlines,
three-lane output delivery, refund/capacity recovery, world persistence, asset
ownership/invalidation and representative malformed-input scenarios. Exhaustive
DTO/shape products, creative pixel/curve details, private UI/storage observers
and duplicate stress runs are intentionally retired. Native checks run through
the canonical mod consumers; they are not replaced by source-string assertions.
A compact six-scenario textured-body check retains declared forward-axis,
horizontal-flip, native-spin and root-texture selection behavior through public
PreDraw and actual FNA CPU vertices; the old 1,080-case product stays retired.
