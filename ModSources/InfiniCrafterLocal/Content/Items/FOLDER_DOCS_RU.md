# Content/Items

Per-instance generated data исполняется общими tModLoader proxy-классами, а не новым C# классом на каждый предмет.

- [InfiniCore.cs](InfiniCore.cs) — station key и ingredient guard; собственная иконка «Сердце кузни» имеет native 24-frame animation. Только отображаемая строка `Terraria/ItemName` получает плавный янтарь → золото → ледяной голубой градиент с 4-секундным циклом через native chat color tags. Plain локализованное Item.Name, save/net, редкость, рецепт и остальные tooltip-строки не меняются; существующие markup-имена не переписываются.
- [GeneratedItem.cs](GeneratedItem.cs) и partials — DTO application, save/net, binding/use/equipment hooks, runtime sprite drawing.
- [GeneratedItem.PrefixLifecycle.cs](GeneratedItem.PrefixLifecycle.cs) — instance-only native prefix/base snapshot и pending token для compact save/net hydration. Восстанавливает native base fields перед реальным `Item.Prefix`, не содержит multiplier/family router и не меняет accepted definition/craft normalization. Placement временно обнуляет contact damage после prefix application; ammo остаётся независимым. Native refusal не форсируется и не заменяется другим prefix.
- [GeneratedItem.RootCombat.cs](GeneratedItem.RootCombat.cs) — exact selected binding → authored root damage/knockback/DamageClass с уже применённым native prefix; hold query выполняется только перед фактическим root spawn. [Native bridge](../../Common/Systems/GeneratedRootCombatSystem.cs) задаёт scoped context до native shoot hooks и восстанавливает исходный Item перед source-stat inheritance; crit/armor, accepted DTO и authored выбор механики не меняются. Неподдерживаемые native module/version/signature отклоняются, не заменяются guessed stats.
- [GeneratedArmorItems.cs](GeneratedArmorItems.cs) — head/body/legs proxy types.
- [GeneratedItem.Tooltips.cs](GeneratedItem.Tooltips.cs) — read-only inventory feedback из exact executable bindings: primary/alternate, while-selected hold, equipped; раздельные stack costs, общая базовая mana для active use и только исполняемые use effects. Локализация — `Mods.InfiniCrafterLocal.RuntimeTooltip` в существующих EN/RU HJSON.

Use policy задаёт явные action, stackCost и contactDamage. Наличие projectile в программе не означает обязательный projectile-use и не выбирает primary owner: действует принятый `runtimeProgram`/binding. `AttackSpec`, `RuntimePlanAuthored` и family/delivery routers не являются текущим контрактом. Authored tooltip prose и gameplay routing по prose/name/category запрещены; finite localized feedback из typed runtime facts разрешён и не меняет механику. `realization`/`selfEvaluation` не отображаются. Secondary/child actions остаются bounded.

Tooltip hook не гидратирует, не нормализует и не проецирует Item, не трогает vanilla stats, prefix/craft normalization и не выбирает механику. Базовая mana показана до player-dependent скидок; hold/equipped не берут её. Placement отдельно объясняет недоступность принятого экземпляра до слома и возврата. Длительности содержат точные тики и секунды (≈ при округлении); числовая культура берётся из текущего языка UI. Ore sense отображается как boolean-подсветка, не обещает неисполняемый radius.

Необычное while-selected поведение Цепного шара сохранено: это забавный authored способ управления, а не ошибка. Tooltip прямо объясняет запуск при выборе без кнопки использования; имена предметов не участвуют в этой проекции. `hideUseGraphic` остаётся решением Gameplay Author, tooltip не принуждает launcher к видимости.
