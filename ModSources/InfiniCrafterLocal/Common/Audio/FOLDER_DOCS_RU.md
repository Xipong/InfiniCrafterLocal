# Common/Audio

Sound selection and optional live cue bridge.

- `InfiniSoundLibrary.cs` — maps explicit profiles/effect/onHit codes/catalog ids to Terraria `SoundStyle`.
- `InfiniLuminanceSoundBridge.cs` — optional loop/live sound cue bridge.
- `InfiniFutureSoundCatalog.cs` — future catalog seam; query fields are inert unless explicit catalog ids/paths are authored.
