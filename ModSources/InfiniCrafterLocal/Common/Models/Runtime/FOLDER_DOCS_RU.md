# Common/Models/Runtime — Проекция DTO в движок

`GeneratedItemData.Apply.cs` проецирует принятый DTO в Terraria Item; `.Debug.cs` фиксирует результат этой проекции. `GeneratedEquipmentBounds.g.cs` создаёт `tools/generate_equipment_bounds.py`; содержимое вручную не редактировать.

Namespaces и имена типов сохраняются. Папка обозначает владельца исходников, а не новый API/слой исполнения.
