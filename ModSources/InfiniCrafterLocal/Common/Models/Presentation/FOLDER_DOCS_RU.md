# Common/Models/Presentation — Visual/VFX модели

`SpritePresentation.cs` задаёт sprite geometry; `Vfx*Spec.cs` задают typed visual/audio/material contracts. Эти модели не выбирают gameplay и не дают новый gameplay authority.

Namespaces и имена типов сохраняются. Папка обозначает владельца исходников, а не новый API/слой исполнения.
