# Common/Systems/Placement — Placement и material claims

Все partials `GeneratedPlacementLedgerSystem` остаются вместе: placement authorization, persistent groups/returns, prefix witness, placed-body admission/net/view/light. `GeneratedPlacedBodyNativeAdapter*` — проверенные native placement/draw-hook boundaries. Derived view/light не отделены в новую ledger.

Namespaces и имена типов сохраняются. Папка обозначает владельца исходников, а не новый API/слой исполнения.
