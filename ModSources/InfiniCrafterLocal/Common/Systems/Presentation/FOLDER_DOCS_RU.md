# Common/Systems/Presentation — Native presentation hooks

`GeneratedCursorItemPresentationSystem.cs` рисует exact selected instance в cursor preview. `GeneratedPlacedBodyDrawSystem.cs` рисует read-only placed-body view. Это только размещение исходников: игровой UI и asset paths не меняются.

Namespaces и имена типов сохраняются. Папка обозначает владельца исходников, а не новый API/слой исполнения.
