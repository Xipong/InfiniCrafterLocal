# Common/Systems/Utility — Native quick-use

`GeneratedQuickUseSystem.cs` связывает QuickHeal/QuickMana с существующими generated item effect hooks. Utility-use не приписан combat или presentation, поскольку это независимая native effect-entry lane.

Namespaces и имена типов сохраняются. Папка обозначает владельца исходников, а не новый API/слой исполнения.
