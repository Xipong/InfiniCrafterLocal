# InfiniCrafterLocal v0.4.254 — начать

**Основной Windows-вход: `OPEN_INFINICRAFT.bat`.** Он готовит проектное `LocalGenerator/.venv` и открывает GUI, но не скачивает модели и не устанавливает мод. Это дерево подготовки к альфе, не опубликованный альфа-релиз.

1. Подготовь Python 3.11+ с Tcl/Tk, stable tModLoader/ParticleLibrary/Luminance и свои text/image endpoints.
2. Полностью распакуй проект, открой основной BAT, настрой LLM и изображения.
3. Сохрани настройки и нажми «Запустить сервер»; проверь правильные version/root/config в health.
4. Установи исходники мода отдельным `01_INSTALL_MOD_TO_TMODLOADER.bat` (удаляет старую папку), затем Build + Reload.
5. Получи Core и соедини A/B в «Кузне чудес».
