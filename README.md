# Infinicraft — InfiniCrafterLocal

**Подготовка к альфе · версия исходников 0.5.02.** Это рабочее дерево, не объявление опубликованного альфа-релиза.

Соедини два предмета Terraria в «Кузне чудес», чтобы получить новый предмет с собственной механикой, описанием и PNG. Мод работает в tModLoader; отдельный LocalGenerator обращается к выбранным тобой текстовой модели и генератору изображений.

## Начать играть

1. Подготовь Python 3.11+ с Tcl/Tk и stable tModLoader с ParticleLibrary/Luminance.
2. Распакуй проект и открой **`OPEN_INFINICRAFT.bat`**: он готовит локальное окружение `LocalGenerator/.venv` и открывает **Infinicraft Studio в браузере**.
3. Выбери маршруты текста и изображений, сохрани настройки и запусти генератор. Мод устанавливается отдельно.

**[Пошаговая установка и первый крафт](docs/user/START_RU.md)** · [Настройки](docs/user/SETTINGS_RU.md) · [Если не работает](docs/user/DIAGNOSTICS_RU.md)

Модели и внешние игровые зависимости не скачиваются автоматически. Облачные запросы могут расходовать квоту или деньги твоего провайдера. Успешный запуск сервера ещё не доказывает доступность модели или качество генерации.
