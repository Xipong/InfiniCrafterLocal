# Infinicraft

<img src="docs/assets/IFC-discord-icon.png" alt="Infinicraft: символ бесконечности над наковальней" width="160">

**Объединяй предметы Terraria и получай новые — со своей механикой, описанием, рисунком и эффектами.**

В «Кузне чудес» ты выбираешь материалы, а нейросети создают результат. **Studio** открывается в браузере и позволяет настроить генерацию, запустить её и посмотреть журнал.

**[Скачать мод](https://github.com/Xipong/InfiniCrafterLocal/releases/tag/v0.5.6)** · [Первый крафт](docs/user/START_RU.md) · [Руководство офлайн](START_HERE.html) · [Решение проблем](docs/user/DIAGNOSTICS_RU.md)

## Начать играть

Нужны **Terraria, stable tModLoader, ParticleLibrary и Luminance**.

1. Скачай `InfiniCrafterLocal.tmod` из [официального релиза](https://github.com/Xipong/InfiniCrafterLocal/releases/tag/v0.5.6). Помести его в пользовательскую папку **Mods**, которую можно открыть из tModLoader, и включи мод вместе с зависимостями.
2. В главном меню нажми значок **IFC** справа вверху. Studio откроется в браузере; та же кнопка есть в **Mod Configuration → InfiniCrafter Local**.
3. Выбери источник текста и изображений, сохрани настройки. На «Рабочем столе» Studio нажми **«Запустить генератор»**, затем **«Проверить»**.
4. Создай **«Сердце кузни» (InfiniCore)** и держи его в инвентаре. Открой инвентарь, положи материалы в кузню и нажми **«Сковать»**.

В готовой сборке для **Windows x64** Studio, LocalGenerator и Python уже упакованы в мод. При первом запуске среда распакуется в папку сохранений tModLoader. Устанавливать Python или скачивать исходники для этого пути не нужно.

**Играешь у друга?** Генерацию настраивает хозяин мира. Подключающимся игрокам нужны мод и игровые зависимости; свои модели и аккаунты не требуются.

[Подробная установка и первый крафт →](docs/user/START_RU.md)

<details>
<summary>Запускать Studio без игры</summary>

После первого открытия из мода в папке сохранений tModLoader появится `InfiniCrafterLocal/Studio/OPEN_INFINICRAFT.bat`. Она открывает ту же Studio с теми же настройками и кэшем. После обновления мода один раз открой Studio через его меню, чтобы обновить среду и открывалку.

Прежняя [OPEN_INFINICRAFT.bat](OPEN_INFINICRAFT.bat) из архива или репозитория тоже поддерживается. Для неё нужен **Python 3.11+**; она использует собственные настройки и кэш. Архив `Source_and_LocalGenerator.zip` в релизе предназначен для этого способа запуска и разработки.

</details>

## Выбрать способ генерации

Текст и изображения можно подключать независимо. Модели и аккаунты в поставку не входят; облачные запросы расходуют квоты выбранного сервиса.

| Вариант | Как работает | Кому подойдёт |
|---|---|---|
| **Бюджетный гибрид** | Бесплатная облачная текстовая модель + современный компактный локальный генератор изображений | Для старта с небольшими расходами, если есть подходящее железо |
| **Всё в облаке** | Текстовый API + Image API либо доступные аккаунту функции ChatGPT / Codex через Studio | Если не хочется устанавливать модели или выделять им память |
| **Всё локально** | Своя текстовая LLM и свой генератор изображений | Если хватает ресурсов на обе модели, контекст и игру |

**Для облачного текста** нужны достаточное окно контекста и уверенная работа со структурированным JSON. Бесплатные квоты зависят от сервиса. **Для ChatGPT / Codex** доступ к изображениям проверяется отдельно: подписка и успешный вход сами по себе его не гарантируют.

**sd.cpp — внешняя необязательная зависимость.** Для этого локального источника укажи свой `sd-server.exe` или нажми **«Скачать sd.cpp»** в Studio, выбери совместимую сборку и отдельно подготовь веса. При облачных изображениях sd.cpp не нужен.

[Подключить текст и изображения →](docs/user/PROVIDERS_RU.md) · [Войти в ChatGPT / Codex →](docs/user/CODEX_IMAGE_OAUTH_RU.md)

## Системные требования

Основа — компьютер, на котором комфортно работает **твой набор модов**. Для полностью облачной генерации достаточно ресурсов для игры и Studio. Таблица ниже — ориентир для **бюджетного гибрида** с последовательной генерацией картинок.

| Ресурс | Минимальный ориентир | Рекомендуемый запас |
|---|---|---|
| **RAM** | **16 ГБ** для лёгкого модпака, Studio и экономного размещения компонентов | Игра и генератор работают одновременно без постоянной подкачки |
| **VRAM** | **8 ГБ** для компактного квантованного генератора; при необходимости энкодер и VAE размещены на CPU | Веса и рабочие буферы помещаются вместе с игрой и драйвером |
| **Процессор** | Справляется с игрой и перенесёнными на CPU компонентами | Фоновая генерация не мешает игре |
| **SSD** | Вмещает весь комплект весов, Studio и кэш предметов | Есть свободное место для роста кэша, обновлений и смены моделей |

**Минимальный пресет: Q6 у генератора + Q4 у его текстового энкодера.** При достаточном запасе памяти выбирай более высокую точность. При жёстком дефиците можно пробовать **Q5 + UD-Q3**, принимая возможное ухудшение качества. Энкодер картинок — отдельный компонент, он не заменяет LLM, создающую предмет. VAE тоже входит в комплект; компоненты и кванты должны поддерживаться выбранной моделью и движком.

Начни с отдельной картинки и умеренного исходного разрешения **при запущенной игре**. Сначала попробуй разместить энкодер и VAE на CPU: это освобождает VRAM, но увеличивает расход RAM и может замедлить крафт. Выгрузка весов между стадиями не равна вычислению на CPU — компонент может возвращаться на GPU.

Считай память под **весь комплект и рабочие буферы**, включая обработку референсов и удаление фона, если они используются. Размер файла генератора не равен пиковому расходу. Универсального минимума для всех моделей и модпаков нет; имеющиеся прогоны без игры не подтверждают его.

## Атлас открытий

Нажми **K**, выбери созданный предмет и открой **«Родословную»**: атлас покажет известные связи предметов текущего мира. Колесо приближает карту, перетаскивание двигает её, **⊙** возвращает общий вид. Щелчок по созданному предмету открывает карточку; **«Назад»** возвращает предыдущий экран.

Для обычных предметов Terraria и других модов можно установить **Recipe Browser**. Наведи курсор на узел и используй его клавишу поиска предмета под курсором — по умолчанию **Mouse3**. **K** вернёт атлас с сохранённым выбором. Если исходный мод или точная идентичность предмета недоступны, переход отключён.

## Обновление

Текущая поставка — **[0.5.6](https://github.com/Xipong/InfiniCrafterLocal/releases/tag/v0.5.6)**. Обновляй мод и внешний генератор из одного релиза; перед обновлением сохрани миры, персонажей, настройки и кэш.

Поддерживаемые сохранённые предметы не требуют нового мира только из-за minor-обновления. Совместимость действительно старых форматов проверяется отдельно — [порядок обновления и граница поддержки](docs/user/UPDATING_RU.md).

<details>
<summary>Что изменилось в этой поставке</summary>

- Встроенная Studio проверяет целостность среды и готовность интерфейса перед обновлением внешней открывалки. Настройки, кэш, профили и внешние модели хранятся отдельно.
- Прерванная распаковка или очистка продолжается только для подтверждённых файлов установщика. Неизвестные и изменённые файлы сохраняются; автоматического отката данных нет.
- Телепорт к курсору учитывает положение ног персонажа и перевёрнутую гравитацию, сохраняя ограничения дальности и препятствий.

Состав готового `.tmod` и архива проверяй по **Assets** и описанию релиза. Тег или исходники сами по себе не подтверждают наличие собранного пакета.

</details>
